# 小米音效自动切换 · AudioFx Auto

**连接不同蓝牙设备，自动换上对应的音效和 EQ；断开蓝牙，自动恢复手机外放方案。**

适配 **小米 14 · 澎湃 OS 3 · Android 16**，通过 **Shizuku** 工作，**无需 Root**。音效切换可在锁屏、熄屏时进行。

Automatic per-device sound effects and EQ for Xiaomi 14 / HyperOS 3, powered by Shizuku without root.

**[下载 V6.4 APK](downloads/AudioFxAuto_v64.apk?raw=true)** · [安装与使用](docs/USAGE.md) · [自行构建](docs/BUILD.md) · [隐私说明](PRIVACY.md)

## 它解决什么问题？

手机外放、蓝牙耳机、汽车音响，适合的声音处理往往不同。这个 App 把音效选择变成每台设备各自的方案，连接后自动应用，省去反复打开系统设置。

你可以这样设置，所有选项都能在 App 内修改：

| 音频输出 | 音效方案示例 | EQ 示例 |
| --- | --- | --- |
| 手机扬声器 | 杜比全景声 + 沉浸声 | 低频增强、高频柔和 |
| 蓝牙耳机 | 小米音效 + 沉浸声 | 自定义预设 |
| 汽车蓝牙 | 原声 | EQ 不参与处理 |

按实际音频输出选择方案，而不是只看蓝牙开关。设备名称相同，也可以按设备标识区分。

## 能做什么

- **每台设备独立配置**：外放和各个蓝牙音频设备分别选择杜比、小米音效或原声，以及沉浸声与 EQ。
- **锁屏、熄屏自动切换**：前台服务监听输出变化，使用 Shizuku 调用系统音效。
- **10 段 EQ 预设**：内置平直和暖声预设，支持新建、复制、编辑、删除。
- **记录设备**：记住识别过的蓝牙输出设备，也可从已配对设备中添加规则。
- **同步系统 EQ 页面**：点击按钮，将当前设备的 EQ 写入系统图形均衡器。
- **本机保存**：无账号、无云同步、无广告；应用未声明联网权限。

### 两种“同步”分别是什么？

| 操作 | 是否自动 | 是否需要亮屏 |
| --- | --- | --- |
| 音效、沉浸声、EQ 实际听感随设备切换 | 自动 | 不需要 |
| 系统设置里的 EQ 滑杆显示当前预设 | 点击“同步到系统均衡器” | 需要解锁亮屏 |

**V6.4 的系统页面同步需要主动点击。** 后台切换不会弹出系统页面，系统滑杆显示最近一次同步的曲线。直接从系统设置打开 EQ 页，可能重新应用系统自己保存的曲线。

## 安装前看这里

这是针对特定小米系统实现的适配项目，**不是所有 Android 手机通用的均衡器**。

| 项目 | 当前适配范围 |
| --- | --- |
| 手机 | 小米 14，设备代号 houji |
| Android | Android 16 / API 36 |
| 系统 | 澎湃 OS 3；已验证固件 OS3.0.307.0.WNCCNXM |
| 系统音效组件 | MiSound 15-3.2-3-20260507 |
| Shizuku | 13 或更新版本，以无线调试 / ADB 的 shell 模式启动 |
| Root | 不需要；本项目不使用 root 模式的 Shizuku |

系统页面同步有精确版本检查，其他固件可能被拒绝；其他机型或系统版本没有兼容性承诺。

## 三步开始

1. 安装并启动 [Shizuku](https://shizuku.rikka.app/guide/setup/)，再安装上方 APK。
2. 打开 App，授予 Shizuku、附近设备和通知权限，开启“自动切换”。
3. 在“设备”中配置外放与耳机方案；在“均衡器”中编辑预设，再为设备选择它。

旧版升级：先停止自动切换，直接覆盖安装，保留应用数据。手机重启后需重新启动 Shizuku，再开启自动切换。

系统页面同步：暂停音乐，保持设备不变和解锁亮屏，进入“均衡器 → 同步到系统均衡器”。它会更新系统自定义 EQ，操作期间不要触摸滑杆。

更完整的步骤、预期结果和恢复方法见 [使用说明](docs/USAGE.md)。

## 当前边界

- 外放只能选杜比或小米音效；“原声”用于蓝牙耳机等输出。
- 原声模式下不应用自定义 EQ，也不启用本 App 的沉浸声设置。
- “平直”会主动归零；“保持现有 EQ”表示不写入，两者含义不同。
- 通话、有线、USB 和不明确的混合输出会暂缓处理。
- Shizuku 停止、权限被回收、系统限制后台运行时，自动切换无法继续。
- 停止自动切换会保留当前音效，不自动恢复到安装前的设置。

## 开发

Java 17+、Python 3、Linux x86_64；使用锁定版本和 SHA-256 的独立构建工具，不依赖 Gradle。

```sh
python3 build.py
python3 validation/run_tests.py
```

默认生成未签名 APK；自行安装需要自己的签名密钥。发布签名私钥不在仓库中，完整步骤见 [构建说明](docs/BUILD.md)。

核心实现分为 App 界面/后台服务、Shizuku UserService、原生音效调用与主动页面同步四部分，见 [实现说明](docs/ARCHITECTURE.md)。
