# 安装与使用

## 准备

当前适配小米 14、Android 16、澎湃 OS 3。系统页面同步限定 OS3.0.307.0.WNCCNXM 和 MiSound 15-3.2-3-20260507。其他版本可能无法工作。

先按 [Shizuku 官方说明](https://shizuku.rikka.app/guide/setup/)使用无线调试或电脑 ADB 启动 Shizuku。App 要求 shell 模式，UID 2000，不使用 root 模式。

## 安装和授权

1. 下载仓库 downloads 下的 AudioFxAuto_v64.apk 并安装。
2. 已装旧版时，先停止自动切换，再覆盖安装；保留应用数据。
3. 打开 App，授予 Shizuku、附近设备和通知权限。
4. 开启“自动切换”，等待状态显示已连接控制服务、已识别输出。
5. 如系统限制后台运行，在应用设置中允许后台运行和自启动。

预期：状态页显示当前输出及方案。授予 Shizuku 允许本 App 以 shell 身份操作系统音效，只应安装自己信任的 APK。

如用电脑安装，将 APK 放在当前目录，手机已授权该电脑的 ADB 后执行：

```sh
adb install -r AudioFxAuto_v64.apk
adb shell am start -n dev.mi14.audiofxauto/.MainActivity
```

预期输出 Success 并打开 App。这两条命令只安装、启动本应用，不执行 EQ 同步。

## 配置设备

“设备”页有手机扬声器、已识别蓝牙设备和“其他蓝牙设备”默认方案。也可添加已配对设备。

点开设备后选择音效模式、沉浸声和 EQ，点击保存。当前输出立即应用；其他设备在下次成为音频输出时应用。

外放可选杜比或小米音效；蓝牙还可选原声。原声模式下 EQ 不参与处理。设备名称仅用于显示，实际按设备标识匹配。

## 配置 EQ

- 平直：全部为 0，主动清除本 App 管理的频段增益。
- 暖声：从左到右为 0、25、50、25、0、0、−25、−25、−25、0%。
- 自定义：新建、复制预设后编辑十段增益，再保存。
- 保持现有 EQ：不写入频段，与“平直”含义不同。

滑杆编辑先改变预览，保存后才应用。新建预设后，还需要在设备方案里选用它。

## 同步系统图形均衡器

1. 暂停音乐，保持手机解锁亮屏、设备连接不变。
2. 在 App 的“均衡器”或“设置”中点“同步到系统均衡器”。
3. 核对设备及预设，点击“开始同步”。
4. 系统页打开后不要拖滑杆或切换页面，等待几秒，最长约 40 秒。
5. 返回 App，查看同步结果；可以手动退出再打开系统页确认曲线保留。

这会覆盖系统“自定义”EQ。系统以 0.5 dB 为档位，有些 App 的 5% 步进值会取整，原预设不改。原声和保持现有 EQ 的方案不执行页面同步。

后台设备切换继续使用底层通路，不自动拉起系统页。系统页显示最近一次同步的曲线；直接打开系统页可能把它保存的曲线重新写回声音处理器。

页面同步若中途失败，可能留下部分频段修改。锁屏、设备变化或读回不符时会停止。返回 App 后会尝试重新应用当前设备的底层方案。

## 锁屏、熄屏使用

保持 Shizuku 和自动切换服务运行，连接/断开蓝牙输出，稍等几秒即可。手机重启后需重新启动 Shizuku 和本 App 服务；不承诺无 Shizuku、后台被结束时仍可运行。

## 常见问题

**声音变了，系统滑杆没有变？**
底层 EQ 与系统页面私有配置不同。使用主动同步按钮；本版没有后台自动刷新系统滑杆。

**显示“小米 EQ 无法读回确认”？**
该固件的一条读取接口不可用。App 保守报告已发送但未确认，不代表听感一定无效，也不等于读回验证通过。

**原声不能在外放下选择？**
当前系统只有连接耳机等输出时提供原声，App 沿用这个范围。

**USB、有线或通话时不切换？**
当前版本对这些情况暂缓处理。

**安装提示签名不一致？**
不同密钥的 APK 不能覆盖安装。自行构建需持续使用自己的密钥。不要为了绕过错误直接卸载有配置的旧版。

## 停止与恢复

关闭自动切换会保留当前音效。如声音异常，停止自动切换，在系统设置里手动选择音效和 EQ。页面同步前的曲线可在本机诊断日志 BEFORE_PERCENT 中找到；日志不会自动上传。

反馈问题时先阅读 [隐私说明](../PRIVACY.md)，优先描述版本、操作和现象，不上传完整日志。
